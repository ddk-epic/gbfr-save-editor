# gbfr-save-editor

Reads Granblue Fantasy: Relink save files, `SaveData*.dat`, into typed records. The save has no fixed record layout. It stores a flat list of values, each tagged with the thing it is about and the characteristic it holds.

The vocabulary falls into three layers. Game language names what the player sees. Save language names how the save stores it. Reading language names what the project builds to turn one into the other.

## Game language

Terms follow the English translation of the game, spelled as the game spells them. The archive often names the same thing differently; that name appears only where the archive is meant, such as `ability.Key`.

| Term             | Archive                    | Avoid                                  | Definition                                                                                  |
| ---------------- | -------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------- |
| **Character**    | `chara`                    | unit, crewmate                         | One playable or guest member of the crew.                                                   |
| **Captain**      | `chara`                    | protagonist, MC                        | Gran or Djeeta, whichever the save picked at the start.                                     |
| **Skill**        | `ability`                  | ability                                | An active move a character learns. A character equips four at a time.                       |
| **Trait**        | `skill`                    | skill, perk                            | A passive effect with a level, carried by sigils, weapons, wrightstones and summons.        |
| **Sigil**        | `gem`                      | gem                                    | An equippable item holding up to two traits. A character equips twelve.                     |
| **Weapon**       | `weapon`                   | gear                                   | The one weapon a character wields, carrying its own traits and at most one wrightstone.     |
| **Wrightstone**  | `item`                     | stone                                  | An item carrying three traits, applied to a weapon.                                         |
| **Summon**       | `summon`                   |                                        | A summon with a trait and an equip bonus. Four are equipped, shared by the whole party.     |
| **Loadout**      |                            | preset, build                          | A named, saved set of one character's weapon, sigils and skills.                            |
| **Party set**    |                            | team, preset                           | A saved party of up to four characters with their gear.                                     |
| **Mastery**      | `limit_bonus`, `ap_tree_*` | ap tree, node                          | A node on a character's mastery tree, bought with MSP.                                      |
| **Master level** | `chara_master_exp`         | mastery level                          | The level MSP spent on a character pays for.                                                |
| **Over Mastery** | `limit_bonus_param`        | over-mastery, overmastery, limit bonus | One of a character's four rolled bonus lines, at level 1 to 10.                             |
| **Master Trait** | `skillboard_effect`        | skillboard, board cell                 | A cell on a character's master trait board, in one of the styles Insight, Essence and Crux. |
| **Fate Episode** | `fate_episode`             | story, episode                         | A character's side story.                                                                   |
| **Curio**        | `item`                     |                                        | An item appraised into rewards.                                                             |

## Save language

| Term                                            | Avoid                                          | Definition                                                                                                                                                                                                                                                                                                                                                                                                            |
| ----------------------------------------------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **System data**, **Slot data**                  | section, blob, region                          | The save's two blobs. System data holds settings. Slot data holds game progress and is the part the readers interpret.                                                                                                                                                                                                                                                                                                |
| **Unit**                                        | cell, record, row                              | One stored value, carrying its entity, its attribute, its value type and its values. A unit is identified by the pair of its entity and its attribute, never by either alone.                                                                                                                                                                                                                                         |
| **Entity**                                      | UnitID, unit id, owner, subject, slot          | The thing a unit is about, such as one character, one sigil or one curio. Save wide values sit at entity 0.                                                                                                                                                                                                                                                                                                           |
| **Attribute**                                   | IDType, type number, property, field, column   | The characteristic a unit holds, such as a sigil's level or a character's experience. Every unit of one attribute shares a single value type across the whole save.                                                                                                                                                                                                                                                   |
| **Value type**                                  | data type, primitive                           | The primitive a unit's values are stored as, one of bool, byte, ubyte, short, ushort, int, uint, long, ulong and float. Fixed per attribute.                                                                                                                                                                                                                                                                          |
| **Entity range**                                | base, offset, section                          | A span of entity numbers reserved for one kind of thing. Characters start at 10000, sigils at 30000, weapons at 40000.                                                                                                                                                                                                                                                                                                |
| **Mastery block**                               | character progress, progress block, skillboard | The entity range holding everything one character has earned through the mastery system: Over Masteries on the first four entities, then mastery nodes and master trait cells spread across the rest. Nodes and cells sit under the same attribute and are told apart by which key table recognises the hash. A character's level, experience and base stats are not in here; they sit on the character's own entity. |
| **Sigil id**, **Weapon id**, **Wrightstone id** | slot, slot id, index, serial                   | The number the game gives one owned sigil, weapon or wrightstone, stored with it and used wherever something refers to it. Handed out in order and never reused, so the gaps in a long played save are deletions. Each kind counts on its own, so an id says nothing without knowing its kind. Not positional: it does not say where the save stores the thing, which is its entity.                                  |
| **Equip position**                              | slot, sigil slot, index                        | A place on a character, a loadout or a party set member that holds a reference to something equipped, counted from 0: twelve sigil positions, four skill positions, one weapon. A position holds an id or a key, never an entity.                                                                                                                                                                                     |
| **Empty slot**                                  | null, blank, unset                             | A unit holding the hash of the empty string, which the save uses for an unfilled slot. Distinct from an unresolved key, which is a filled slot the tables cannot name.                                                                                                                                                                                                                                                |

## Reading language

| Term               | Avoid                            | Definition                                                                                                                                         |
| ------------------ | -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Archive key**    | name, game key, id               | The game table key a hash stands for, such as `GEEN_027_14` or `PL1200`. The save stores hashes; readers resolve them to archive keys.             |
| **Key table**      | lookup, dictionary, index        | A generated map from hash to archive key for one game table, built from the extracted game archive.                                                |
| **Unresolved key** | unknown key, missing key, orphan | A hash with no entry in its key table, carried as `#` followed by 8 hex digits. It means the generated tables cannot say what the hash stands for. |
| **Domain**         | module, feature, area            | One game term's attributes, reader and checks, usable without any other domain it does not name.                                                   |
| **Reader**         | parser, mapper, loader, decoder  | A function turning the units of one domain into typed records. Readers are the only place that assigns meaning to a unit.                          |
